# Sparsh Gupta — Portfolio

Personal React + Vite portfolio based on the supplied design. Includes Sparsh’s own profile image, CV, five verified certificate images, projects and experience. Project preview panels are custom text designs, **not** screenshots of completed projects.

## Run in VS Code

Open this exact folder in the terminal (the folder containing package.json), then:

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Replace the two project preview panels with screenshots of your own projects when available. The LPU merit certificate naming a different person has not been included.
